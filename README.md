# COMBINADA

La quiniela de los amigos.

Aplicación web para 5 jugadores con:

- Autenticación mediante Supabase
- Jornadas
- Partidos
- Pronósticos 1/X/2
- Responsables de jornada
- Resultados
- Cuotas
- Desempate por cuota
- Premios
- Jornadas ganadas
- Clasificación de temporada
- Panel de administración

## Stack

- React
- Vite
- Supabase
- Cloudflare Pages
